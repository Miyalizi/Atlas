字节跳动的 Trae 国内版（Trae CN）目前仍是免费的，基于 VS Code，可以装 `.vsix` 插件，内置豆包 Seed Code、DeepSeek、Kimi、GLM、Qwen 等国产模型，也能接自定义的模型服务商。

两个模式值得一试：

- **SOLO Coder**：在已有项目上迭代，先出计划，再读文件、写代码、跑测试。
- **SOLO Builder**：从零搭项目，会生成需求文档、装依赖、开预览，可以接 Supabase、Vercel、Stripe。

适合：想零成本上手、不想折腾代理和 API Key 的人，或者给家人朋友推荐入门工具。

注意：

- 对话内容会上传云端处理，有商业机密的项目先关掉数据收集，或干脆别用。
- 商业化方案还没公布，免费期不确定，别把关键工作流绑死在上面。
- 用 Supabase 之类后端时，一定要看[vibe coding 安全清单](/posts/vibe-coding-security/)。

规则写在 `.trae/rules.md`，思路和 [AGENTS.md](/posts/agents-md-guide/) 一样。更多国产选项见[国产 Coding Plan 对比](/posts/china-coding-plans/)。
