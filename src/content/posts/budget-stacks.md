## 每月 100 元左右：国产为主

- **Kimi Code Plus 年付（约 ¥79/月）** 或 **GLM Coding Plan Lite（¥118/月，年付约 ¥94/月）**：主力编程额度，接进 Claude Code 或 OpenCode 使用。
- **DeepSeek API 充值几十元**：批量杂活。
- **Trae CN（免费）**：图形界面和临时项目。

优点是国内直连、付款方便；缺点是遇到特别难的问题时，国产模型偶尔会力不从心。国产各家对比见[国产模型怎么选](/posts/china-models-guide/)。

## 每月 20 美元左右：一个海外主力

- **Claude Pro**（主力）或 **ChatGPT Plus**（主力），二选一。
- 再加少量 DeepSeek API 做批量。

如果你主要写前端、做 Web 应用，两者都行；更在意 Hook 和自定义流程选 Claude，更在意并行和沙箱选 Codex。

## 每月 200 美元左右：重度玩家

- **Claude Max 5x（$100）**：主力，Opus 5.5 随便用，含 Fable。
- **ChatGPT Plus（$20）**：第二意见和并行备份。
- **国产 Coding Plan 一个**：第三个额度池，也用来对比国产模型的进展。
- **API 余额 $30–50**：Gemini 4 Argon 做长文档、DeepSeek 做批量。

如果你已经在 Max 5x 上经常顶到周限额，再考虑 Max 20x。

## 通用建议

- 每个月底看一次实际用量，砍掉没用满的。
- 注意汇率和支付方式，海外订阅在国内的支付和合规问题见[在国内用海外模型](/posts/overseas-models-in-china/)。

为什么是这样组合，见[全球订阅性价比](/posts/global-best-value/)。
