单看哪家最便宜意义不大，**组合起来覆盖不同任务**才是个人开发者的最优解。下面是我认为当下性价比最高的几种组合（价格为月付美元，国产为人民币）。

## 按性价比排

1. **Claude Pro（$20）**：Claude Code 是目前最成熟的编程 [Harness](/posts/harness-engineering/)，Sonnet 5.5 和 Opus 5.5 都能用。对大多数人，这是第一笔该花的钱。
2. **ChatGPT Plus（$20）**：Codex App 的 worktree 并行很好用，GPT-6.1 Sol 和 Sonnet 5.5 能力相当，相当于第二个额度池。还附带 ChatGPT 的日常能力。
3. **Cursor Plus（$8）**：如果你喜欢编辑器里的补全和 Composer 2.5 这种便宜快模型。
4. **国产 Coding Plan（¥79–118/月起）**：Kimi Plus 或 GLM Lite，当作额外额度池，接进 Claude Code 用。见[国产 Coding Plan 对比](/posts/china-coding-plans/)。
5. **DeepSeek API 预充值**：几十块钱能用很久，专门跑批量任务。
6. **Google AI Pro（$19.99）**：已经需要 Google 云盘的人顺便订。

## 三种典型组合

- **入门（约 $20/月）**：Claude Pro 一个就够。
- **主力（约 $40–50/月）**：Claude Pro + ChatGPT Plus，再加少量 DeepSeek API。两个 5 小时窗口轮流用，基本不会被卡。
- **重度（约 $100–200/月）**：Claude Max 5x 做主力，ChatGPT Plus 或国产 Coding Plan 做备份。

更具体的人民币预算方案见[三档预算配置](/posts/budget-stacks/)。

## 别踩的坑

- **别同时订好几个功能重叠的 $20 档**又都用不满。先审计一遍订阅，再谈优化 token。
- **别买长年付**。2026 年各家的额度和档位一年变好几次（Codex 一年里 5 小时窗口取消又恢复）。
- **别只看“用量倍数”**。各家额度口径不同，没法直接换算，只能实测。
