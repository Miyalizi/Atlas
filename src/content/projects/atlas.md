## 为什么自己搭

用过几个现成的博客平台，最后都卡在同一件事上：内容之间没有关系。一篇文章写完就沉下去，三个月后连我自己都想不起它和哪几篇在讲同一个问题。所以我想要一个**会自己长出连线**的博客：正文里写一个站内链接，被引用的那篇就自动知道“谁提到了我”，首页的星图上也会多出一条线。

## 怎么做的

- **内容就是 Markdown 文件**，放在仓库里，用 git 管版本。以后换工具，带走的是一堆纯文本。
- **Astro 生成静态页面**，部署在 Cloudflare Pages，推送到 main 就自动上线，一分钱不花。
- **双向链接和星图在构建时算好**：扫描所有正文里的站内链接，得到一张图，详情页底部的“引用了本文”和首页星图都从这张图来。
- **每篇文章的封面是一张星图**，由文章 id 决定星座的形状，同一篇永远长一样，不用我找配图。
- **专题系列**把同一主题的文章按阅读顺序串起来，解决“文章多了不知道从哪读起”的问题。

## AI 在里面做了什么

几乎所有代码都是我和 Claude Code 一起写的。我的分工是定方向、写验收标准、看截图挑毛病；它负责实现、跑构建、截图给我看。流程和[一个人的 AI 开发流水线](/posts/solo-dev-ai-workflow/)里写的一样，规则写在仓库的说明文件里，见[一份好的 AGENTS.md](/posts/agents-md-guide/)。

最大的体会是：**“好不好看”没法写成测试**，只能靠一轮轮截图对比。所以我让 Agent 每次改完都给出改前改后的截图，明暗两套、桌面和手机各一张，这比读 diff 有用得多。
